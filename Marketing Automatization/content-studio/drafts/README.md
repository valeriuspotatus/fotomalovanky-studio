# drafts/

Generated blog packages land here as local files. Drafts only. Nothing in this
folder is published anywhere automatically.

## How to use

1. Run the generate prompt (see [../README.md](../README.md)) in your LLM.
2. Save the returned JSON here as `YYYY-MM-DD_<handle>.json`
   (example: `2026-04-20_darek-pro-maminku-omalovanky-z-fotek.json`).
3. Optionally save a human-readable version as `.md` next to it.
4. Run the quality checker over it before doing anything else.
5. Replace every `[OVĚŘIT]` with real, verified data.
6. Follow [../docs/MANUAL_SHOPIFY_WORKFLOW.md](../docs/MANUAL_SHOPIFY_WORKFLOW.md)
   to paste it into Shopify as a hidden/draft article. Author: David.

## Rules

- Draft only. Never publish from here.
- No fabricated reviews, numbers, prices, delivery promises, or guarantees.
- CZ only. Author is always David.
